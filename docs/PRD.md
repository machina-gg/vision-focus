# VisionFocus

## 1. 概要

VisionFocusは、「やるべきことに時間を使う」ためのChrome拡張機能。単なるサイトブロッカーではなく、「現状の可視化（分析）」「誘惑の遮断（ブロック）」「目標の再認識（モチベーション）」の3段階で、ユーザーの生産性を最大化するセルフコントロール・システム。

## 2. 背景・課題

### 市場の課題

- 既存のブロッカーは「禁止」するだけで動機付けが弱い
- 最新ツールはAI多用により動作が重く、かつ高価（$3〜$10/月）
- サーバー連携型サービスへのプライバシー懸念
- 「なぜブロックされているのか」を思い出させる仕組みがない

### 解決策

- 非AIによる爆速な動作とAPIコストゼロの実現
- 月額$1.99という競合最安クラスの低価格
- 「なぜ今それをしてはいけないのか」を視覚的に訴えかけるページ表示
- ユーザーデータ（設定・閲覧履歴）はローカルに保持

## 5. 非機能要件

### 対応環境

- **ブラウザ**: Google Chrome（最新版）
- **Chrome拡張機能**: Manifest V3準拠
- **レスポンシブ**: デスクトップのみ（Chrome拡張のため）

### パフォーマンス

- 拡張機能のロード時間: 100ms以下
- ブロックページ表示: 即時
- 分析データの更新: リアルタイム（1秒単位）
- メモリ使用量: 50MB以下

### セキュリティ・プライバシー

- ユーザーデータはローカルストレージに保存
- 閲覧履歴・ドメイン名は外部送信しない
- GA4による匿名使用統計（オプトイン、閲覧データは含まない）
- 最小限の権限要求

### 保守性

- TypeScriptによる型安全性
- ESLint/Prettierによるコード品質維持
- Vitestによる単体テスト

### 多言語対応

- **対応言語（MVP）**: 英語（デフォルト）、日本語
- **言語判定**: ブラウザの言語設定による自動判定（手動切替不要）
- **実装方式**: chrome.i18n API
- **対象範囲**:
  - 拡張機能内のすべてのUI
  - Chrome Web Storeのストアリスティング（説明文・スクリーンショット）
- **将来対応**: スペイン語、中国語（簡体字）、韓国語等

## 6. マネタイズ

### 収益モデル: 投げ銭 + アフィリエイト推薦

**全機能を無料で提供する。** 機能制限による課金は行わない。

| 手段                     | 内容                                                             |
| ------------------------ | ---------------------------------------------------------------- |
| 投げ銭                   | Buy Me a Coffee への支援リンク（ヘルプタブ、レポート表示時）     |
| 書籍のアフィリエイト推薦 | 時間術・集中に関する書籍を推薦するダイアログ（書影・説明文つき） |

### この方針を選んだ理由

- **サーバー費用が発生しない**: 全データを `chrome.storage.local` に保持するローカル完結型のため、月額課金を正当化する継続コストがない
- **コア価値を制限したくない**: 「集中を取り戻す」価値はブロック・ダッシュボード・分析にあり、そこを制限すると製品の良さが伝わらない
- **広告ネットワークが使えない**: Manifest V3 はリモートコードの実行を禁止しており、AdSense / AdMob 等の広告 SDK は動作しない。そのため収益手段としてアフィリエイトと投げ銭を選ぶ

### 機能上限について

課金の線引きとしての上限は存在しない。ダッシュボードスタイルの上限（10件）のみ、**選択ボタンを横並びで表示する UI の都合**で設けている（`src/constants/limits.ts` の `MAX_PRESETS`）。

### 推薦ダイアログの方針

- **表示場所**: 価値を実感した直後（CSV エクスポート後、壁紙ダウンロード後、レポート初回表示時）
- **表示しない場所**: 新規タブ（ビジョンダッシュボード）とブロック画面。集中させる画面であり、外部リンクは離脱経路になるため
- **頻度**: 既定で30日に1回まで。「今後表示しない」を選択可能
- **開示**: アフィリエイトリンクである旨を明記する（Chrome Web Store のポリシー要件）
